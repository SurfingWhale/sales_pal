- **Code:** `lib/templates.ts`, `lib/scriptPick.ts`, `components/ScriptManager.tsx`, `components/ChatPicker.tsx`, `components/ChatAnalysis.tsx`.

## Rules

- One collection (`pitchTemplates`), one editor, one place to use a script on one person (Pesan).
- The stage comes from the lead's position. The best-fitting script is put in, and the reason is shown.
- Archived and draft scripts are never offered.
- Placeholders follow [interaction-model](../interaction-model.md) § Data honesty.
- A match score is not a closing probability.
